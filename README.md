# Dembix AI Lab

Repositorio público de investigación de **Dembix**, laboratorio de Inteligencia Artificial con sede en Cantabria. Aquí publicamos la metodología completa, los datos crudos y los resultados de nuestros estudios, para que cualquiera pueda auditarlos, replicarlos o construir sobre ellos.

## Misión

Investigar, experimentar y divulgar sobre Inteligencia Artificial, construyendo herramientas y publicando resultados reproducibles. Creemos que la investigación en IA no debería ser un territorio cerrado — por eso cada estudio incluye no solo las conclusiones, sino todo lo necesario para repetirlo de forma independiente.

## Estudios publicados

| Fecha | Estudio | Resumen |
|---|---|---|
| Agosto 2026 | [Comparativa de LLMs gratuitos en tareas de negocio](./2026-08-comparativa-llms-negocio) | Evaluación de ChatGPT, Gemini y Claude (versiones web gratuitas) en 5 tareas reales de negocio local, con evaluación ciega asistida por IA. |

## Estructura de cada estudio

Cada carpeta de estudio sigue esta estructura:

```
nombre-del-estudio/
├── paper.md                 → El artículo completo (resumen, metodología, resultados, conclusiones)
├── metodologia/              → Todo lo necesario para replicar el experimento (prompts exactos, criterios)
├── datos-crudos/              → Las respuestas/datos originales, sin editar
├── evaluacion/                → Los informes de evaluación completos, tal cual se generaron
└── resultados/                → Tablas de resultados en formato abierto (CSV) para análisis propio
```
